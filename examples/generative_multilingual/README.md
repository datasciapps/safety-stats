# Generative example: multilingual jailbreak rewrites

Every other example in this repository conditions on a **fixed set of prompts**. This one
does not have any. The evaluator declares a structural taxonomy with target weights and a
frozen stochastic rewrite kernel; the prompts are generated by sampling that design, so
path selection and rewrite generation are part of the uncertainty the interval reports.

The design here compiles to **264 terminal structural paths**, of which a 1,200-draw
evaluation touches a few hundred. The point is that you never enumerate them.

## What is real and what is simulated

The rewrite kernel is `DeterministicFakeKernel` and the target model is
[`simulated_target.py`](simulated_target.py). **No model is called and nothing is
evaluated.** That is deliberate, and it is what makes the example worth reading: because
the true failure probability of every structural path is declared in that file, the true
root risk is computable in closed form, and the interval the package reports can be
checked against it rather than merely inspected.

Everything else is the real code path — taxonomy compilation, counter-based selection,
rewrite execution with retry and deduplication, Inspect dataset materialization, the
outcome join, and inference. Swapping in a real evaluation replaces one function; see
[Using a real model](#using-a-real-model).

## The design

| level | source | values |
|---|---|---|
| `problem_class` | seed manifest | chemical synthesis (0.6), biological agents (0.4) |
| `semantic_seed_id` | seed manifest | 8 fixed seeds, equal within class |
| `language` | inline arm | english 0.4, french 0.2, german 0.2, maltese 0.2 |
| `style` | inline arm | plain 0.5, conversational 0.3, formal 0.2 |
| `wrapper` | `wrapper-arms.csv` | direct_request 0.5, roleplay 0.3, nested_task 0.2 |

Two authoring features earn their place rather than being decoration:

- a **constraint** removes `nested_task` under Maltese, because the wrapper depends on
  instruction-following the rewriter cannot hold in a low-resource language. Those paths
  are outside the declared design, not merely rare. The surviving wrappers renormalize to
  0.625 / 0.375.
- **context weights** give English a different style mix (0.4 / 0.3 / 0.3), since it is
  the highest-resource language here.

The declared truth concentrates risk where the structure predicts: Maltese carries 20% of
the target weight at roughly 7% risk, against 2% for English. True root risk is **0.03504**.

## Running it

Compile the taxonomy and see what it contains:

```bash
python examples/generative_multilingual/compile_tree.py
```

Run one complete evaluation, plan to interval:

```bash
python examples/generative_multilingual/run_evaluation.py
```

```
design          : direct, 1200 rewrites
rewrites        : 1200 accepted, 0 duplicates rejected, 0 exhausted

root
  true risk           0.03504
  point estimate      0.03250
  95% upper bound     0.04224
  covers the truth    True
  method              clopper_pearson_one_sided_missingness_robust
  failures / draws    39 / 1200

nodes reported 390, unsampled 13
```

Measure whether the intervals actually cover, over many evaluations:

```bash
python examples/generative_multilingual/validate_coverage.py --replicates 400
```

```
root
  empirical coverage   0.960   (nominal >= 0.95)
  mean point estimate  0.03491   (truth 0.03504)
  mean upper bound     0.04491
  bound slack          0.00987
```

Each replicate redraws the sample as well as the outcomes, so what is measured is the whole
procedure, not the noise in one fixed sample. Coverage lands just above nominal rather than
far above it, and the mean point estimate sits on the truth.

## Three things the example is built to show

### A single interval may miss, and that is the guarantee working

`run_evaluation.py` reports four language slices pointwise at α = 0.05. About one run in
five, one of them sits below the truth and prints `False`. That is not a defect: a 95%
bound is wrong 5% of the time by construction, and four of them miss at least once about
19% of the time. `validate_coverage.py` is the honest check, and it reports 0.958–0.988
across the four slices.

### Some questions are not subtrees

"What is the risk in Maltese?" cannot be answered by a hierarchy node. Semantic seeds are a
mandatory stratification frontier, so `language` sits *below* them and English is 32
separate nodes rather than one. Reading a per-language number off the tree means taking a
worst case across those 32 nodes, which at ~30 draws each gives bounds around 0.13–0.36 —
useless.

The estimand is still perfectly well defined: a declared-weight mean over the matching
terminal paths. The draws landing in it are still independent conditional on their count,
so the same exact construction applies. `estimate_slice` does exactly that, and the same
question answered properly gives 0.027–0.112. **This estimator exists because building this
example exposed the gap.**

### The stratum floor has a price, and it is not rounding

`plan-stratified.yaml` sets `minimum_rewrites_per_stratum: 40` so no seed can be missed.
Holding the outcomes fixed and varying only the design:

| design | draws per stratum | coefficient ratio | kernel | root bound |
|---|---|---:|---|---:|
| direct | — | 1.000 | exact | 0.00249 |
| stratified, no floor | 144 / 160 | 1.000 | exact | 0.00249 |
| stratified, floor 40 | 145–157 | 1.033 | weighted | 0.00254 |

Proportional allocation here is **exactly free** — the weights divide 1,200, so the
coefficients stay equal and the sharp Clopper–Pearson kernel is retained. The entire 2.0%
penalty comes from the floor pushing allocation away from proportional. That is a
deliberate purchase: 2% of bound width for a guarantee that no seed goes unsampled.

## Using a real model

The offline path stops at `simulated_target.evaluate`. To run it for real:

1. run `run_evaluation.py` to materialize `datasets/dataset.jsonl` and the ledgers;
2. evaluate that dataset with Inspect, scoring it with your judge;
3. ingest the resulting logs, and pass the normalized observations through
   `samples_from_observations`;
4. call `join_outcomes` and `estimate_tree` exactly as the script does.

Replace `DeterministicFakeKernel` with a provider-backed kernel implementing the
`RewriteKernel` protocol at the same time. Note that `prompts.restricted.csv` is the only
artifact containing prompt text — the ledgers carry hashes.

## Limitations

- **There is no CLI for the generative path.** `inspect-safety-stats analyze` handles fixed
  plans only, so this example is driven by scripts.
- **No comparisons.** `estimate_tree` covers one cohort at a time. `shared_rewrites` already
  materializes paired arms, but nothing consumes the pairing yet.
- **Slices are pointwise.** They overlap the tree's nodes, so they cannot join its Šidák
  frontiers and are not part of a simultaneous family.
- **The judge is not modelled.** [Judge misclassification](../../docs/judge-misclassification.md)
  applies to fixed designs; nothing here corrects for a fallible scorer.
