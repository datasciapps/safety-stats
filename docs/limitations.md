# Limitations log

A record of limitations found or assumed while using the package on real evaluations. Most come
from the open-weight study in [`examples/open_weights/`](../examples/open_weights/):
one model, HarmBench's 300 standard and contextual behaviors and XSTest's 250 safe prompts,
20 rollouts per prompt, thinking off and on. Others come from a review of the package's
architecture, a survey of prompt generation, and issues. Nothing here is a commitment. Changes to
the package still follow [CONTRIBUTING](../CONTRIBUTING.md), with an issue a maintainer agreed to
for class B and C changes.

The entry numbers are stable, so other documents can cite them, such as "L51". An entry
describes the package as it was when the limitation was found, and file and line references are
from that time. The last column says what the package on `main` does about it now:

- **Addressed**: a change on `main` removes the limitation. "Experimental" means the change is
  opt-in and marked experimental in the docs.
- **Partly**: a change on `main` covers part of it. The column says which part is left.
- **Open**: nothing on `main` changes it yet.
- **Open upstream**: the limitation lies in Inspect AI.

The evidence column says how far the entry was checked:

- **verified**: reproduced, with the evidence named;
- **observed**: seen once in a real run, not yet reduced to a test;
- **assumed**: inferred from reading code or docs, not yet checked.

"The study's run log" is the log kept with the study's notes on the `demo/open-weights` branch.

| L1 | A paired comparison (`pair_key`) fails with `PAIR_BROKEN` when one arm has an unscored rollout. | L2 | Under prompt-level independence, 250 or 300 prompts decide few claims at 5% to 10% thresholds. Rollout independence is not merely an assumption about the model: every rollout is a fresh sample, so for the fixed prompt set it follows from the generation procedure, up to batch-dependent numerics. Prompt-level independence matters for robustness to within-prompt dependence and for any reading beyond the fixed prompts (L11). | open-weight study, planner and main run | verified (report.json `group_risks`) | Partly: each claim's verdict is reported under every declared independence profile. | L51 | Worst-of-k is estimated by putting each prompt's observed rate into 1 − (1 − p)^k, which runs low because the curve is concave. For k up to the rollouts per prompt, 1 − C(n − x, k)/C(n, k) is unbiased for each prompt and lies in [0, 1], so the weighted mean over independent prompts can be bounded like any mean. It gives 8.82% at k = 10 for Qwen with thinking on (harm) against the plug-in's 8.23%, and 3.90% for Nemotron with thinking on against 3.57%.
